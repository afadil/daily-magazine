02 · Governance · CAISI national-security testing
02
Pre-release

Frontier models go to the Commerce Department first.

Microsoft, Google DeepMind, and xAI signed on to share pre-release state-of-the-art systems with the U.S. government through the Department of Commerce's Center for AI Standards and Innovation (CAISI) for national-security evaluation. The labs join Anthropic and OpenAI, who agreed earlier; the practical effect is that the five frontier shops now route their next-generation weights through a government testbed before any external launch.

The frame matters. This is not regulation by statute — it is a voluntary protocol that has quietly become the industry's default. For builders, the load-bearing question is what "evaluation" expands to mean: today it is CBRN, cyber-offense, and autonomy; tomorrow it could include model behaviors that touch enterprise integrations. Track the eval rubric, not the press release.

03 · Platforms · Claude on AWS FOR YOU
03

Claude Platform shows up inside AWS.

Anthropic launched the Claude Platform on AWS: the full Claude API — Messages, Files, Message Batches, Managed Agents, Agent Skills, tool use, code execution — available through native AWS endpoints, billed through AWS, authenticated through IAM. It is not Bedrock-with-a-bow; it is Anthropic's own platform fronted by AWS plumbing, so you get the surface you build against on Claude.com without paying the procurement tax of standing up a second vendor.

For enterprise architects this collapses a real friction point. You can route Claude traffic through the same VPC, SCP, KMS, and billing pipeline as the rest of the org's AWS footprint while keeping the latest API features the moment Anthropic ships them. Combined with spread 04's Fast mode on Opus 4.7, the production gap between "experiment in claude.com" and "deploy in prod" just closed by a notch.

Opus gets a fast lane

Anthropic added research-preview Fast mode to Claude Opus 4.7 on the Developer Platform. Pass speed: "fast" with model claude-opus-4-7 and the fast-mode-2026-02-01 beta header, and you get materially higher output-token throughput on the same weights — at premium pricing. It is the first time the lab has shipped a deliberate speed/cost dial on the flagship rather than steering customers to Sonnet for latency.

The bet behind the pricing is that some workloads — agent loops, interactive coding, real-time review — pay more for wall-clock than for tokens-per-dollar. If your eval rubric treats latency as a feature, run the same prompt set with and without the flag this week and decide. Anything where a human is staring at a cursor will likely justify it; batch backfills almost certainly won't.

05 · Strategy · OpenAI consolidates FOR YOU
05

One team, one surface, one model

OpenAI is collapsing ChatGPT, Codex, and the developer API under a single product organization led by Codex chief Thibault Sottiaux. The pitch internally is a "super app" that pulls the Atlas browser into the same shell. The industrial logic is unambiguous: the assistant, the coding agent, and the API have been converging on the same models and the same tool-use surface for months, and running three competing roadmaps was producing three subtly different agent loops. Sam Altman is also dangling two months free for any enterprise that migrates to Codex within thirty days, with a one-click move tool.

For builders, the read is straightforward. If you are maintaining glue between the Assistants API and Codex features, expect that seam to disappear — and the IDE surface to be the front door. The interesting strategic question is whether the unified team ships faster than Anthropic's split-but-coordinated structure across spreads 03 and 04.

06 · Capital · JPMorgan reclassifies AI

2026 tech budget · JPMorgan Chase
$19.8B

AI moves from R&D to core infrastructure.

JPMorgan Chase formally reclassified its AI investments from experimental R&D to core infrastructure inside the 2026 tech budget — about $19.8 billion total, with 2,000 staff dedicated to AI build-out. The accounting move is the news. Once spend stops being R&D, it stops being a discretionary line item the board can quietly trim, and the systems running on it inherit the same uptime, audit, and depreciation regime as the trading floor's plumbing.

The signal for software teams: if the biggest bank on the Street has decided AI is a load-bearing utility, the procurement gravity in regulated industries will follow. Expect vendor questionnaires to harden, expect SOC2 and model-risk reviews to converge, and expect "we have a pilot team" to stop being an acceptable answer in the back half of the year.

08 · Design tools · Figma FOR YOU
08

Code and canvas stop pretending they're separate.

Figma's May 12 essay, What the Design-to-Code Loop Unlocks, is the clearest statement yet of where the tool is heading. Interviews with Alex Kern (an engineer on AI-powered creation) and Gui Seiz (design director of AI at Figma) describe a true roundtrip: take a workflow that starts in Claude Code into Figma, render the canvas, edit there, and ship the result back to code without re-translating intent. The frame is no longer "designer hands off to developer" — it is one document with two views.

Practically, this lands as the design-system case for MCP and Figma's canvas-side agent surface. If your team owns a component library, the gap that mattered last year — the one where a Figma spec drifted three releases ahead of the shipped CSS — is the gap closing. Worth thirty minutes this week to try a single roundtrip on a real component and see whether the loop holds under your team's review process.

10 · Infrastructure · Cloudflare Workflows V2 FOR YOU
10

50K concurrent workflows, replayable by default.

Cloudflare shipped Workflows V2 with a step-based, deterministic execution model: each step is isolated, replayable, and idempotent, so a workflow can resume from the exact step that failed without re-running completed work. The platform now sustains up to 50,000 concurrent workflows on a single account, with native primitives for compensation, dynamic fan-out, and durable timers.

For anyone who has built the same primitives by hand on top of Temporal, SQS+Lambda, or a homegrown saga library: this is the second platform after Azure Durable Functions to treat deterministic replay as the default, not the opt-in. Pair this with Workers AI and the agent-fleet primitives Cloudflare shipped during Agents Week, and the edge-native long-running-agent story is the one to beat for greenfield work.

Eat your own platform

None of this is internal-only infrastructure. Everything we built sits on top of products we ship.

3,683 (93% R&D)

Cloudflare's iMARS tiger team spent eleven months building the internal AI engineering stack used by 60% of the company — and the load-bearing decision is that they used the same products Cloudflare sells. AI Gateway routes every LLM call through a single proxy Worker that handles per-user attribution, model catalog, and permission policy without any client-side config. Workers AI does on-platform inference. MCP Portal unifies tool access. The result is a three-layer system — Platform, Knowledge, Enforcement — where every layer is a SKU you can buy.

The bit worth stealing is the Knowledge Layer. The team auto-generates an AGENTS.md file for each of 3,900+ repos by pulling Backstage metadata, analyzing the repo structure, and mapping the result to entries in Cloudflare's Engineering Codex. That gives every agent that walks into a repository a freshly-generated context file that already knows which standards apply — without any human writing it.

The Enforcement Layer is the bit that closes the loop. An AI code reviewer sits in CI on 100% of merge requests; in the first thirty days it completed 131,246 review runs across 48,095 MRs in 5,169 repositories with a median review time of 3:39. Reviews ground out against the same Engineering Codex the AGENTS.md files were generated from — so the standards a developer's agent reads in are the standards the reviewer enforces on the way out. The model is a closed loop, not two independently-drifting prompts.

The transferable insight is the Code Mode optimization at the MCP layer: by collapsing 34 underlying GitLab tools into two portal tools, they cut per-request context overhead by roughly 15,000 tokens. The lesson for anyone building an internal agent platform is that the expensive part is not the model — it is the context you feed it. Treat your MCP portal as a context-compression budget, and the rest of the stack falls out naturally.
